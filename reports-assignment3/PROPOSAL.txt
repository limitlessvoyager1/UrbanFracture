A3-01 ROOT CAUSE / FILES
dist/audit135.js:
- admit() delegates enemyAct requests to Director148.request.
- P.enemyAct requests before calling its older path and sets directorStarting148 while nested start executes.
- P.start calls its older start first, then registers a new enemy action through Director148.register when not directorStarting148.
dist/director148.js:
- request() checks pressure budget/maxAttackers, state/recovery, impact overlap, response opportunity and other policy.
- register() records an already-created action; it does not enforce admission.
Later shared reaction, knockdown and reassessment guards correctly block physical locks at both entry points but do not replace Director budget admission.
Director request wrappers add firing-lane, grab-exclusivity, chemical restraint, companion protection and crowd-lane rules. Bypassing request can also skip those policies; only the explicit budget bypass is reproduced here.
