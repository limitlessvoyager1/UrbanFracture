Root cause / correction
UF-RENDER-025 correctly invalidates bitmap contents when exact render time changes.
It also discarded each cropped canvas and allocated a new one for every unique
miss, even when the same dimensions were needed next frame. This resource churn
can be reduced without preserving stale pixels or altering native rasterization.

The new private pool holds only retired, inactive canvases with exactly matching
width/height. Retirement deletes each active owner before pooling. Borrowing
removes free ownership and clears the whole canvas before the unchanged native
crop copy. Different dimensions allocate fresh. The free pool is bounded to32
surfaces and4MiB of width*height*4 accounting, with oldest inactive size buckets
supplying eviction and empty buckets deleted. Oversized retirement is skipped.
No actor, action or game instance is stored in the pool. The original same-time
>512cache guard stays unchanged and does not pool its evictions.

This is storage reuse, not content reuse. Native exact-time/flash admission,
512x384readback, alpha thresholds, cop sole rule, crop cap, native draw arguments,
coordinates, scales, interpolation defaults and return behavior remain intact.
Combat behavior, AI, damage/frame configuration, actual deadlines and simulation
timing are unchanged. No readback ROI, scan rewrite, animation quantization,
grapple/counter/wake-up or character-specific correction is included.
