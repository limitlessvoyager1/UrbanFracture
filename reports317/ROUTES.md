# Industrial District route map

| Arrival/section | Available destination after clearing |
|---|---|
| Hydroelectric dam crest | UP → Industrial outskirts |
| Subway engineer destination menu | Industrial District → outskirts |
| Outskirts / Rust Lane | Electrical substation (optional), storage (optional), intersection |
| Rust Lane & Almeida | North, south, east or return west |
| Almeida north | Active railyard |
| Active railyard | Operations building |
| Operations building | Overgrown abandoned rail yard |
| Abandoned rail yard | Three once-only old-car searches; factory road |
| Factory road | Factory entrance exterior; return route |
| Almeida south | Abandoned water-treatment facility |
| Water treatment | Opposite exit → river woods |
| River woods | Chemical plant entrance exterior; return route |
| Rust Lane east | Security checkpoint and smelting entrance exterior |

The factory, chemical plant and smelting facility interiors are reserved for the next layout task. Exterior staging areas remain explorable and offer a return GO. The district does not automatically end at these placeholders.

GO directions match input: UP/DOWN for Almeida branches and doors, LEFT/RIGHT for street ends. Cleared enemies, consumed items and searched cars persist within the current run. Restart starts the chosen section fresh.
