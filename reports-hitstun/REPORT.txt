Outcome
Both enemy action-entry paths now reject ordinary state-changing starts while mandatory hitstun/shock is active, including nonoffensive idle/guard-like starts and hits that have no reaction receipt. The existing synchronized-state and player exemptions remain. No knockdown repair is included.

Root cause
HitReactions298.locked required a clean hitReaction298 record, which force/grab/other paths do not always produce. Direct start additionally exempted non-threat action names. Thus a live physical lock could coexist with a newly created action that replaced its recoil pose.

Correction
locked now uses actual remaining stun/shock (> the unchanged 1e-7 tolerance) and the unchanged Continuity296.paired exception predicate. enemyAct and direct start both use that same predicate without a threat-name exemption. The damage function, timer progression, visual selection code, armor rules, action definitions and prior post-hit reassessment helper are unchanged.
