# Skylar Nova

The built-in image generation tool created the assets `dist/assets/sprites/nova-motion77.png`, `nova-attacks77.png`, `nova-grapple77.png`, `nova-acrobat77.png`, and `dist/assets/nova-portrait77.png`.

Prompts requested detailed 1990s arcade pixel-art sheets depicting the same athletic late-twenties wrestler with auburn hair in a messy bun, green eyes, a red sports-bra top, red full-length tights bearing yellow-white exploding stars, red wrestling boots and black gloves. Separate sheets show idle/walking/guard poses, strikes and dropkick, wrestling/acrobatic poses, and a split/cannonball/headlock/headscissors; the portrait shows her head and shoulders. Each pose uses an isolated flat background and consistent proportions.

Skylar's moves live in `dist/nova77.js` and preserve shared input, defense, health, route transitions, and controller behavior. Combat damage values are initial testing values; the user did not specify exact values or health costs for her attacks.
