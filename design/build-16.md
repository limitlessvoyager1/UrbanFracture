# Build 16 — running, jump height, Marcus pressure and controller recovery

Reina now has eight dedicated running poses, separate from her walk cycle. Double-tap dashes and Shift/R2 running use this atlas with a distance-driven run phase; attacks, jumps, blocks and holds leave the grounded running state. Jump and dash-kick apex increased 70→96 world units (37%); the diving sword inherits the same taller starting height without changing sprite scale.

Marcus encounters alternate rush/flank roles. Normal approach speed 74→82; rushers charge at 98 beyond 125 units and attack head-on. Flankers route through an offset depth lane behind Reina at 116 horizontal / 80 depth speed, faster than rushers. Flanking can start from range as well as when another enemy engages her. Post-attack cooldown .60→.42; cooldown movement penalty reduced for Marcus. Opening second/third activation 8/15→6/12 seconds while retaining initial spacing. No added armor or interruption resistance.

Controller fixes:
- Raw Sony POV hats accept only the eight discrete hat values. An unused axis 9 at zero no longer fabricates a permanent down-right input.
- Startup/focus neutral gating waits for action-button release rather than every direction/axis becoming neutral. Slight drift or a held direction cannot lock the controller out forever.
- Both standard DSX/XInput and raw Sony devices remain supported. Unrecognized raw device names stay available for button setup. Auto selection prefers an actively used standard device; a Device selector can pin the virtual DSX controller when physical and virtual devices coexist.
- Added local button/stick setup, including faces, shoulders, trigger, Options, D-pad and stick axes; release gates prevent duplicate captures and reversed/nonstandard axes are learned. Profiles persist per device ID in this browser. Optional controls can be skipped, setup canceled and mappings reset. Setup pauses the game and captures controls without firing gameplay actions.
- Added prominent Play with Controller link and live connection status above the game. Browser gamepad policy/access failures expose a clear separate-tab recovery notice. Native input cannot override an embedding page's permissions policy or turn DSX mouse-only emulation into a virtual gamepad.
- Standard/raw/custom controller commands go through the same gameplay input path; controller movement edges also feed double-tap dash detection. Existing disconnect/focus safeguards retained.
