# Gate8 playtest focus

Select Nightshade before starting a scene. The card and runtime HUD identify Gate8 integration. R2/F remains her finite six-round handgun. Start with Downtown, then Casino, Stadium and Woodland Lab; use existing scene selector for direct tests. Test melee after exhausting ammunition, the costly forward Special, ammunition pickups, counter choices, normal grabs and environmental hazards. Locked encounters must release after required enemies are defeated.

This build fixes prop contacts and Casino slot cover. It does not add a new Nightshade foreign-weapon profile. Foreign-weapon pickup/idle/attack animations remain pending, so the shared E/R3 guide must not be taken as proof that this feature exists for Nightshade.

Report any rejected actionable input, stuck grab reference, sprite-scale change, unusable exit, repeated loot, or weapon shot passing through a slot machine. Hardware controller testing and owner-approved art/balance remain required. This is a playtest, not a stable release designation.
